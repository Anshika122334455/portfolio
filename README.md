# Portfolio Website 🎨

A modern, attractive, and fully responsive portfolio website built with HTML5, CSS3, and JavaScript.

## ✨ Features

- **Modern Design**: Clean, professional layout with gradient color scheme
- **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Smooth Animations**: Engaging animations and transitions throughout
- **Interactive Elements**: Hover effects, scroll animations, and smooth navigation
- **Performance Optimized**: Throttled event handlers for smooth scrolling
- **Easy to Customize**: Well-structured code that's easy to modify

## 🚀 Quick Start

1. Clone or download this repository
2. Open `index.html` in your web browser
3. That's it! No build process required.

## 🎨 Sections

- **Hero**: Eye-catching introduction with gradient text and animations
- **About**: Personal introduction with animated statistics
- **Skills**: Showcase your technical skills with icon cards
- **Projects**: Display your work with beautiful project cards
- **Contact**: Contact form and social media links
- **Footer**: Professional footer with copyright information

## 📝 Customization

### Update Personal Information

1. **Name and Title** (in `index.html`, line 41-43):
   ```html
   <h1 class="hero-title">
       <span class="wave">👋</span> Hi, I'm
       <span class="gradient-text">Your Name</span>
   </h1>
   <p class="hero-subtitle">Creative Developer & Designer</p>
   ```

2. **About Section** (in `index.html`, lines 72-74):
   - Update the description paragraphs
   - Modify statistics (years of experience, projects completed, clients)

3. **Skills** (in `index.html`, lines 93-139):
   - Add or remove skill cards
   - Update skill names and descriptions

4. **Projects** (in `index.html`, lines 149-214):
   - Replace project titles and descriptions
   - Update project tags
   - Add project links

5. **Contact Information** (in `index.html`, lines 230-242):
   - Update email, phone, and location
   - Add your social media links

### Customize Colors

Edit the CSS variables in `styles.css` (lines 8-16):
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* ... more colors */
}
```
